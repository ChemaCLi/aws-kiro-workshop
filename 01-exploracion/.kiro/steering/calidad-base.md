# Calidad base

Aunque sea una app personal, todo lo que construyas cumple con esto:

- **Nombres claros** para variables, funciones y archivos. Que se entienda qué hacen sin leer el código completo.
- **Funciones pequeñas** con una sola responsabilidad.
- **Separación** entre interfaz, lógica y datos.
- **Errores visibles:** si algo falla, el usuario ve un mensaje claro que dice qué pasó y qué puede hacer.
- **Validación de entradas:** campos obligatorios, números que deben ser números, fechas válidas.
- **Estados de pantalla:** vacío (sin datos todavía), cargando y error.
- **Accesibilidad básica:** etiquetas en formularios, contraste suficiente y uso con teclado.
- **Sin secretos en el código:** nunca pongas contraseñas ni llaves de API en los archivos.
- **README breve** con qué hace la app y cómo ejecutarla.
- **Comentarios en español** solo donde el código no se explica solo.
