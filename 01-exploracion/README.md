# 01 · Exploración (personal)

**Úsalo cuando:** todavía no tienes clara la idea y no te interesa decidir cómo está hecha por dentro.

**Qué hace por ti:** el agente te ayuda a descubrir qué quieres antes de construir, elige herramientas sensatas por ti y se cuestiona a sí mismo para no adelantarse.

## Qué incluye

| Archivo | Para qué sirve |
|---------|----------------|
| `prompt-inicio.md` | El mensaje que pegas en el chat de Kiro para empezar |
| `.kiro/steering/flujo-exploracion.md` | El flujo de trabajo y las reglas de autocuestionamiento |
| `.kiro/steering/preset-tecnico.md` | Las herramientas y la estructura que usará por defecto |
| `.kiro/steering/calidad-base.md` | Lo mínimo de calidad que siempre debe cumplir |
| `.kiro/agents/` | El equipo de agentes (guía, analista, diseñador, constructor, tester, revisor) |

## Flujo

Explorar la idea → Qué necesito → Cómo verifico → Delegar la construcción

En este escenario aceptamos que el resultado nos sorprenda. Lo importante es aprender y llegar a algo que funcione.
