# 02 · Compartible (personal, útil para otros)

**Úsalo cuando:** sabes cómo quieres que estén hechas las cosas (calidad, usabilidad, privacidad), pero todavía estás definiendo qué funciones tendrá. Ideal para validar ideas que quieres mostrar a alguien o publicar de forma personal.

**Qué hace por ti:** el agente define contigo el qué, respeta los principios acordados mientras explora y te avisa cuando una propuesta los rompe.

## Qué incluye

| Archivo | Para qué sirve |
|---------|----------------|
| `prompt-inicio.md` | El mensaje que pegas en el chat de Kiro para empezar |
| `.kiro/steering/flujo-compartible.md` | El flujo de trabajo de este escenario |
| `.kiro/steering/principios.md` | Los principios que la app debe respetar (personalízalos) |
| `.kiro/steering/preset-tecnico.md` | Herramientas por defecto, con pruebas y publicación |
| `.kiro/steering/calidad-base.md` | Lo mínimo de calidad que siempre debe cumplir |
| `.kiro/agents/` | El equipo de agentes |

## Flujo

Definir el qué → Acordar principios → Diseño ligero → Construir y probar → Preparar para compartir

**Personaliza `principios.md`** antes de empezar: es donde está tu "cómo".
